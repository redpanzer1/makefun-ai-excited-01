A small robot stands at the edge of a cliff, watching a giant golden
sunrise rise over a sea of clouds. A quiet moment of awe at the first
light of a new day.

## How to run

```sh
python3 main.py
```

This copies `entry.png` to the make.fun output directory. The output
directory is taken from the `MAKEFUN_OUTPUT_DIR` environment variable
and defaults to `/output`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

## Files

- `entry.png` — the entry image (1024×1024 PNG): a small robot on a
  cliff edge watching a giant golden sunrise over a sea of clouds.
- `main.py` — copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (Python 3 standard library only, no network).
- `README.md` — this file.
- `LICENSE` — MIT license.
- `.makefun/owner.json` — entry owner wallet.
